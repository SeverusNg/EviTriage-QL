# v0.1.0-rc1 candidate notes and external-action assessment

Historical candidate assessment: superseded by the stable
[`v0.1.0`](v0.1.0.md) release.

Status: **local candidate checks pass; no RC tag or release has been created**.

## Candidate scope

The candidate is the bounded offline Java/CodeQL triage pipeline documented in
the README: existing SARIF or a fresh scan converges on normalization, Level
0/1 context, evidence, Replay Analyst/Rebuttal/Judge, conservative TP/FP/NMC
policy, JSONL/escaped HTML reports, and immutable run manifests. No component
automatically dismisses an upstream alert.

Gate G includes executable wheel/sdist construction, a hash-bearing locked
dependency inventory, a CycloneDX 1.5 SBOM, prompt/schema/version freeze
metadata, and a strict checksum manifest. The default offline demo now closes
the exact six-case v0.1 matrix:

- CWE-22 direct TP, canonical-path-check FP, and unknown-wrapper NMC;
- CWE-78 direct TP and exact-allowlist FP;
- a prompt-injection source-comment case that remains inert and retains its
  expected TP decision.

All six sources compile with Java 17. Their Golden SARIF, test supplement, and
eighteen Replay responses are synthetic acceptance fixtures, not real-model or
accuracy evidence. The separate real CodeQL smoke remains query/pipeline
evidence and stops honestly at `CONTEXT_READY`.

## Local acceptance status

The two P0 blockers recorded in the first Gate G tranche are closed:

- the six strict, SHA-bound case contracts map one-to-one to six report rows,
  producing `TP=3`, `FP=2`, `NMC=1` and `auto_dismiss=false` for every case;
- `make release-artifacts` now stages the reviewed example JSONL, escaped HTML,
  corresponding finalized run manifest, demo/case summaries, and
  machine-readable full/security pytest summaries in the release checksum
  closure.

The same-host evidence also includes source-distribution reinstall, full
quality/security checks, network-free/key-free Replay, a fresh Java
17/CodeQL 2.26.1 query-positive smoke over the self-contained six-case Maven
project, and independent `make release-verify`. That real smoke produced four
query results and reached `CONTEXT_READY`; it remains separate from the
six-result synthetic decision fixture. Exact command results and hashes are in
the dated progress log and release handoff.

## Security and interpretation

This software is research infrastructure, not a production vulnerability
classifier. Synthetic Replay labels are pipeline/policy fixtures, confidence
is uncalibrated, reports can contain source excerpts, and no result authorizes
alert dismissal without human review.
