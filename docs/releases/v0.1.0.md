# EviTriage-QL v0.1.0

Released: 2026-07-23

EviTriage-QL v0.1.0 is the first bounded offline research release. It closes
the Java/CodeQL or existing-SARIF path through deterministic normalization,
bounded context and evidence, ordered Analyst/Rebuttal/Judge calls,
conservative TP/FP/NMC policy, and auditable JSONL/escaped-HTML reports. No
component automatically dismisses an upstream security alert.

## Release evidence

- The frozen six-case synthetic matrix covers CWE-22 TP/FP/NMC, CWE-78 TP/FP,
  and an inert prompt-injection case. It produces `TP=3`, `FP=2`, `NMC=1`,
  eighteen accepted Replay calls, and `auto_dismiss=false` for every case.
- The full branch-aware test gate, directly selected security suite, offline
  demo, wheel/source build, SBOM generation, release-manifest validation, and
  `SHA256SUMS` verification run before the hosted release is created.
- A same-host source-distribution clean-room check/demo and separate CodeQL
  2.26.1/Java 17 query-positive scans are recorded in the dated progress log.
  The real scans stop honestly at `CONTEXT_READY` and are not TP/FP/NMC
  decisions.

## Published artifacts

The release assets include the wheel, source distribution, hash-bearing locked
dependency inventory, CycloneDX 1.5 SBOM, strict release manifest,
`SHA256SUMS`, six-case matrix, reviewed example JSONL/HTML/run manifest, and
machine-readable full/security test summaries. The
`evitriage-ql-0.1.0-release.tar.gz` asset preserves the complete directory,
including the uv-generated dotfile. Extract it, then run:

```bash
make release-verify RELEASE_DIR=/path/to/extracted/assets
```

to recheck the checksum closure.

## Interpretation and limitations

This is research infrastructure, not a production vulnerability classifier.
The six labels and Replay responses are synthetic pipeline/policy fixtures,
confidence is uncalibrated, and the example report can contain source excerpts.
There is no second-host reproduction, artifact signature, external provenance
attestation, dependency vulnerability audit, or package-index publication in
this release. Use human review for every security decision and see
[`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md) before operating on
non-fixture code.
