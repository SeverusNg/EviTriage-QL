## Frozen v0.1 contract

The mandatory vertical slice remains:

```text
Java fixture / golden SARIF
→ CodeQL or SARIF ingest
→ SARIF/codeFlows normalize
→ path-function context
→ evidence registry
→ Analyst / Rebuttal / Judge
→ deterministic policy
→ TP / FP / NMC
→ JSONL + HTML report
```

Gate A establishes only the engineering, ProjectSpec, workspace, diagnostics,
storage, and CI substrate. The downstream boxes are not considered delivered by
this entry.

The following work cannot be traded away from v0.1: strict schemas,
evidence/claim reference gates, NMC, Fake/Replay, an offline end-to-end path,
tests, and a run manifest. If schedule pressure requires cuts, the order is
GitHub integration, PostgreSQL, remote clone, complete Gradle support, real model
provider, adaptive context, verification, then calibration.
