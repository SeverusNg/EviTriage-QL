## Frozen v0.1 contract

The mandatory vertical slice remains:

```text
Java fixture / golden SARIF
→ CodeQL or SARIF ingest
→ SARIF/codeFlows normalize
→ path-function context
→ evidence registry
→ Analyst / Rebuttal / Judge
→ deterministic policy
→ TP / FP / NMC
→ JSONL + HTML report
```

Gate A establishes the engineering, ProjectSpec, workspace, diagnostics,
storage, and CI substrate. The 2026-07-21 entries deliver both Gate B input
branches through `SARIF/codeFlows normalize`, then shared path-function context
and an evidence registry. The later Gate D entries deliver bounded offline
Agent analysis and deterministic decisions. The Gate E entries deliver
integrated JSONL/HTML publication, a fixed one-command offline TP/FP/NMC demo,
and both existing-SARIF and scan-to-triage orchestration. The demo assertions
are synthetic test oracles, not accuracy or independent ground-truth evidence.

The following work cannot be traded away from v0.1: strict schemas,
evidence/claim reference gates, NMC, Fake/Replay, an offline end-to-end path,
tests, and a run manifest. If schedule pressure requires cuts, the order is
GitHub integration, PostgreSQL, remote clone, complete Gradle support, real model
provider, adaptive context, verification, then calibration.
